# anion-tv

Kotlin + Compose for TV + Media3. Нативное приложение для Android TV: каталог
аниме и просмотр с пульта. Личное, ставится sideload'ом. UI-тексты и
комментарии — на русском.

**Перед работой прочитать [AGENT.md](AGENT.md).** Там архитектура, конвенции,
команды и — главное — список уже пройденных граблей: неочевидности Kodik,
маршрутизации API, AGP 9 и Gradle, каждая из которых стоила отладки. Правки без
этого контекста с большой вероятностью воспроизведут уже решённую проблему.

**Не реверсить заново то, что решено рядом.** Резолв Kodik целиком лежит в
[../anion-dl/src-tauri/src/kodik.rs](../anion-dl/src-tauri/src/kodik.rs),
проксирование API — в [../anion/middleware.js](../anion/middleware.js), типы
ответов бэка — в [../anion-go/internal/dto/anime.go](../anion-go/internal/dto/anime.go).
Сначала читать их, потом экспериментировать.

История решений по этапам — [PLAN.md](PLAN.md). Установка окружения и что нужно
для тестирования — [README.md](README.md).
