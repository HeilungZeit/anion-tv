# Установка Anion TV

Anion TV распространяется готовым подписанным APK через GitHub Releases. Google
Play и компьютер для обычной установки не нужны.

## Что скачать

1. Откройте страницу [последнего релиза](https://github.com/HeilungZeit/anion-tv/releases/latest).
2. Раскройте блок **Assets**.
3. Скачайте файл `anion-tv-VERSION.apk`.

Файл `.aab` предназначен для магазинов приложений и вручную на телевизор не
устанавливается. `SHA256SUMS.txt` содержит контрольные суммы файлов релиза.

Приложению нужен телевизор или приставка на Android TV с Android 6.0 или новее.

## Вариант 1: установка с USB-накопителя

1. Скачайте APK на компьютер и скопируйте его на USB-накопитель.
2. Подключите накопитель к телевизору и откройте APK через файловый менеджер.
3. Если Android заблокирует установку, откройте предложенные настройки и
   разрешите этому файловому менеджеру устанавливать неизвестные приложения.
4. Вернитесь к APK и подтвердите установку.

Название нужного пункта зависит от производителя телевизора. Обычно он находится
по пути **Настройки → Приложения → Специальный доступ → Установка неизвестных
приложений**. После установки разрешение можно снова отключить.

## Вариант 2: скачать прямо на телевизоре

1. Откройте в браузере телевизора
   `github.com/HeilungZeit/anion-tv/releases/latest`.
2. В разделе **Assets** скачайте `anion-tv-VERSION.apk`.
3. Откройте файл из «Загрузок» и разрешите браузеру установку неизвестных
   приложений, если Android попросит.

На телевизорах с неудобным браузером проще использовать USB-накопитель.

## Вариант 3: установка через ADB

Этот способ предназначен для разработчиков. Включите режим разработчика и
отладку по сети на телевизоре, узнайте его IP-адрес, затем выполните:

```bash
adb connect TV_IP:5555
adb install -r anion-tv-VERSION.apk
```

Если телевизор показывает код беспроводного сопряжения, сначала выполните:

```bash
adb pair TV_IP:PAIRING_PORT
```

## Обновление

Скачайте APK новой версии и установите его тем же способом поверх старой. Не
удаляйте приложение перед обновлением — история просмотра и настройки сохранятся.
Все официальные версии подписываются одним ключом проекта, поэтому Android сможет
проверить обновление.

Если Android сообщает о конфликте подписи, вероятно, установлена неофициальная
или debug-сборка. Удаление такой сборки очистит её локальные данные, после чего
можно установить официальный APK.

## Проверка файла

При желании сравните SHA-256 скачанного APK со значением из `SHA256SUMS.txt`:

```bash
sha256sum anion-tv-VERSION.apk
```

На macOS:

```bash
shasum -a 256 anion-tv-VERSION.apk
```
