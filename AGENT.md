# anion-tv — справочник

Нативное приложение для Android TV: каталог аниме и просмотр на телевизоре.
Личное, ставится sideload'ом, в Google Play не пойдёт. Управление — только пульт.

Пошаговый план и история решений — [PLAN.md](PLAN.md). Здесь то, что нужно
знать, чтобы менять код и не наступить на уже пройденные грабли.

---

## Первое правило

**Не реверсить то, что решено в соседних репозиториях.** Kodik, маршрутизация
API и обход WAF уже разобраны и работают:

| Что | Где смотреть |
|---|---|
| Резолв Kodik целиком, с тестами и реальным `src` | [anion-dl/src-tauri/src/kodik.rs](../anion-dl/src-tauri/src/kodik.rs) |
| Лестница качества, `is_playlist`, `split_quality` | [anion-dl/src-tauri/src/resolver.rs](../anion-dl/src-tauri/src/resolver.rs) |
| Проксирование `/proxy/…` на Cloud Run | [anion/middleware.js](../anion/middleware.js) |
| Заголовок обхода Vercel WAF | [anion-dl/src/app/api/api.config.ts](../anion-dl/src/app/api/api.config.ts) |
| Типы ответов anion-go | [anion-dl/src/app/api/anime.types.ts](../anion-dl/src/app/api/anime.types.ts), [anion-go/internal/dto/anime.go](../anion-go/internal/dto/anime.go) |

Один такой реверс уже был проделан заново и стоил десятка запросов и неверной
гипотезы. Живые проверки — только чтобы подтвердить найденную схему.

## Стек

Kotlin 2.3.20, AGP 9.3.0, Gradle 9.7.0, JDK 17 (годится и JBR 25 из Студии),
Compose for TV (`tv-material` 1.1.0), Media3, Room, OkHttp, kotlinx.serialization.
`compileSdk = 36`, `minSdk = 23`.

Версии — в [gradle/libs.versions.toml](gradle/libs.versions.toml). Помеченные
«проверено» сверены с релиз-нотами; остальные заведомо рабочие, но, возможно,
устаревшие — Студия подсветит их в каталоге. Бампать по одной: media3 и room
ломают API между минорами.

### Конвенции

- **Комментарии и UI-тексты — на русском.** Комментарий объясняет *почему*, а не
  пересказывает код. Если причина неочевидна и стоила отладки — она обязана быть
  записана рядом с кодом.
- **Ничего не выводить «по факту ответа».** DTO зеркалят Go-структуры; меняется
  бэк — правится DTO. Форма ответа фиксируется фикстурой, а не догадкой.
- **Сеть в юнит-тестах не трогается.** Единственное исключение — `resolver-probe`,
  и он не часть CI.
- `internal` по умолчанию для всего, что не является API модуля.
- Никаких `!!` на внешних данных; для отсутствующего поля — типизированное
  исключение с внятным текстом, а не NPE.

## Модули

```
app/                   Compose for TV: экраны, навигация, фокус, апдейтер
core-source/  (JVM)    AnimeSource + AniLibria + Kodik/anion-go
core-resolve/ (JVM)    iframe URL → m3u8: страница плеера, POST, ROT+base64
core-player/  (AAR)    Media3: Referer, скипы, позиция, переролв по 403
core-data/    (AAR)    Room: просмотренное, кэш каталога, синк закладок
tools/resolver-probe/  CLI: живая проверка резолва и источников
```

Зависимости строго в одну сторону:
`app → core-player → core-data → core-source → core-resolve`.

`core-resolve` и `core-source` — **чистый Kotlin/JVM без Android**. Это не
стилистика: самая хрупкая часть обязана гоняться в обычных JVM-тестах и в CLI,
без эмулятора. В anion-dl `attempt_resolve` требовал `AppHandle`, и юнит-тестами
там покрыт только `split_quality` — здесь этой ошибки нет.

## Как это устроено

### Резолв Kodik (`core-resolve`)

Схема перенесена из `kodik.rs`, проверена живьём 12.08.2026:

1. `GET` страницы плеера с `Referer: https://anion.online/` — Kodik подписывает
   параметры под домен-владелец вставки.
2. `POST` на `/ftor` формой из **11 полей**: `d`, `d_sign`, `pd`, `pd_sign`,
   `ref`, `ref_sign`, `type`, `id`, `hash`, `bad_user`, `cdn_is_working`.
   Заголовки: `Referer` = URL страницы плеера, `Origin`, `X-Requested-With`.
3. `src` каждой ссылки: сдвиг латиницы (18 первым, остальные перебором) + base64.
4. Качество берётся **из имени файла**, не из ключа ответа, и добирается
   подменой числа в URL с проверкой `#EXTM3U`.

Медленный путь — парс `app.player_single.*.js`, поиск `atob("…")` с коротким
путём из одного сегмента — включается, только когда известный адрес отказал.

### Источники (`core-source`)

`AnimeSource` — один интерфейс, две реализации:

- **AniLibria** — `https://anilibria.top/api/v1`, без ключа. В эпизоде сразу
  `hls_480/720/1080` и полные отрезки `opening/ending`. Резолва нет.
- **Kodik** — каталог из anion-go, поток через `StreamResolver`.

### Данные

anion-go доступен **только по `/proxy/api`**. Запросы к `/api/…` попадают в
каталог serverless-функций Vercel (там SSR) и возвращают мусор.

Обход Attack Challenge Mode — заголовок `X-Anion-Client: anion-dl`. Значение
общее с anion-dl намеренно: своя метка ничего не защищает, заголовок
подделывается тривиально, а правило под это значение уже заведено.

## Грабли, на которые уже наступили

### Kodik и API

- **`GET /ftor?type=..&id=..&hash=..` отдаёт 404.** Голых параметров эндпоинту
  мало, нужен POST с подписями. В PLAN §2 когда-то стояла обратная «поправка»,
  выведенная из чтения kodikwrapper, — она неверна и снята.
- **`vInfo.*` важнее одноимённых `var`.** На странице сезона в адресе стоит
  `season`, а серия внутри уже `seria` со своим id и хэшем. Возьмёшь `var` —
  получишь ссылки не на ту серию.
- **`var ref`, а не поле `ref` из `urlParams`**: во втором оно percent-кодировано,
  и подпись под него не подходит.
- **Ключ качества в ответе врёт.** У `links["720"]` наблюдался URL с `480` в
  имени файла.
- **404 на 1080p при живых 720/480** — нормальное поведение CDN, не ошибка.
- **`Referer: https://kodikplayer.com/` обязателен** и для манифеста, и для
  каждого сегмента, иначе 403 на середине серии.
- **Страница плеера, открытая напрямую в браузере, отдаёт «данной страницы не
  существует»** — нужен Referer сайта-встраивателя. Смотреть трафик плеера через
  DevTools бесполезно и по другой причине: инструменты чтения сети не видят
  запросы внутри iframe.
- **`skips` у anion-go — только момент начала.** Длина есть во внешней модели
  (`VideoSkips.Opening.Length`), но `VideoSkipsDTO` её отбрасывает. Поэтому
  `Segment.stopSeconds` необязателен; при `null` плеер берёт окно в 90 секунд.
- **Одна запись `videos` — это «серия N в озвучке X».** У тайтла бывает под сотню
  записей и три десятка озвучек вперемешку; список озвучек собирается
  группировкой по `data.dubbing`.

### Compose на телевизоре

- **Обработчик клавиш обязан стоять до `focusable()`.** `Modifier.onPreviewKeyEvent{}.focusRequester(r).focusable()` работает,
  а `focusRequester(r).focusable().onPreviewKeyEvent{}` — нет: обработчик не попадает
  в фокус-узел. Плеер при этом выглядит зависшим — «ни паузы, ни перемотки», —
  но `BackHandler` продолжает работать, потому что он системный, и баг кажется
  необъяснимым.
- **Экран без фокуса вообще не получает пульт.** Полноэкранному плееру фокус
  нужно запрашивать явно, после того как ушёл индикатор загрузки: `MessagePane`
  с кнопкой может перехватить его на себя.
- **Ключи `LazyColumn`/`LazyGrid` обязаны быть уникальны**, иначе
  `IllegalArgumentException: Key "N" was already used` роняет весь экран при
  отрисовке. Уникальность обеспечивает источник данных, а не UI.
- **`scrollToItem` на неприсоединённом `LazyListState` висит вечно.** Если
  состояние ещё не связано с реальным `LazyColumn` (экран в ветке загрузки),
  вызов приостанавливается навсегда — и всё, что стоит следом в том же
  `LaunchedEffect`, не выполняется. Симптом самый неприятный: вечная
  «Загрузка…» без ошибки, краша и единой строчки в логе. Прокрутку выносить в
  отдельный эффект, срабатывающий по появлению данных.
- **OK работает по схеме ютуба на ТВ**: при скрытой панели первое нажатие лишь
  показывает контролы с фокусом на паузе и не трогает воспроизведение,
  останавливает уже второе — по самой кнопке. Исключение — идущий опенинг: там
  OK сразу пропускает. Вариант «OK = мгновенная пауза» пробовали, он сбивает:
  случайное нажатие останавливает серию.
- **Эмодзи вместо иконок не годятся.** Системный шрифт рисует ⏸/▶ цветными
  картинками — на тёмной панели это оранжевое пятно. Транспортные иконки
  нарисованы через `Canvas` (`TransportIcon`), без зависимости от иконочных
  библиотек.
- **Списки дедуплицируются на входе в состояние.** Страницы каталога умеют
  пересекаться, и повтор карточки роняет весь экран дубликатом ключа. Кроме
  источников (`KodikSource`) чистка стоит и в `CatalogViewModel`/`HomeViewModel`.
- **Экран деталей на ТВ живёт от «продолжить»**: главная кнопка должна вести на
  недосмотренную серию с сохранённой позиции, а не на первую.

### Сборка

- **Kotlin поддерживает вложенные блочные комментарии.** `/api/*` внутри KDoc
  открывает второй уровень, и файл падает с «Unclosed comment». Писать `/api/…`.
- **`fun test() = TODO()` не компилируется** — нужен явный `Nothing` или блочное
  тело `{ TODO() }`.
- **Заглушки тестов помечены `@Ignore("не реализовано, ЭN")`**, иначе `build`
  красный от нереализованного. Снимать вместе с реализацией.
- **`kotlin.test` в Android-модулях не резолвится** при встроенном Kotlin AGP 9 —
  там `org.junit.Test`. В JVM-модулях `kotlin.test` работает.
- **JVM-модули обязаны иметь `jvmToolchain(17)`.** С `sourceCompatibility`
  вместо него Kotlin берёт таргет от JDK, на которой запущен Gradle, и сборка
  из терминала (17) расходится со сборкой из Студии (JBR 25).
- **Загрузчик gradle-враппера спотыкается на редиректе** `services.gradle.org` →
  GitHub Releases: `SocketException: Unexpected end of file from server`, при том
  что curl тот же файл тянет. Лечится подсовыванием архива в
  `~/.gradle/wrapper/dists/gradle-<версия>-bin/*/` (удалив `.part` и `.lck`).

### AGP 9

- `org.jetbrains.kotlin.android` **больше не применяется** — Kotlin встроен.
- Compose-плагин при этом **всё равно обязателен**.
- `tv-foundation` **не существует**: при стабилизации Compose for TV его
  содержимое уехало в обычный `androidx.compose.foundation`.
- Hilt не подключён — вместо него ручной `AppContainer`. Совместимость Hilt со
  встроенным Kotlin не проверялась, а сломанный DI-плагин блокирует всю сборку.


```bash
./gradlew :tools:resolver-probe:run --args="kodik 15"
```

```bash
./gradlew :tools:resolver-probe:run --args="resolve <iframe-url> 720"
```

Пробник заканчивает каждую команду скачиванием манифеста и проверкой `#EXTM3U` —
«пришёл JSON» успехом не считается.

Сборка и установка APK:

```bash
./gradlew :app:assembleDebug && adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`adb` лежит в `~/Library/Android/sdk/platform-tools`, в PATH его может не быть.

## Тестирование

| Слой | Чем | Где |
|---|---|---|
| `core-resolve`, `core-source` | JUnit + фикстуры + MockWebServer | JVM |
| Живой резолв | `resolver-probe` | JVM, вручную |
| `core-data` | JUnit; миграции — `MigrationTestHelper` | JVM / эмулятор |
| `core-player` | JUnit на скипы и переролв | эмулятор + бокс |
| `app` | D-pad через `adb shell input keyevent` | ТВ-эмулятор + бокс |
| Производительность | профайлер, прокрутка ≥ 30 fps | **только бокс** |

Фикстуры — реальные ответы API в `core-source/src/test/resources/fixtures`,
сняты 12.08.2026. Обновлять их пробником, а не руками.

Чего не хватает для полной проверки: **дешёвого ТВ-бокса на 1.5–2 ГБ и его
пульта**. Эмулятор на Apple Silicon не покажет ни просадок прокрутки, ни
выедания памяти постерами — а это два из шести подводных камней плана. ТВ-образ
для эмулятора тоже не установлен (есть только телефонный).
